# Елла Недвижими Имоти

Production website for the real-estate agency, built with React, TypeScript, TanStack Start, Vite, and Supabase. The public site is deployed at <https://ellaimoti.pages.dev/>.

## Development

This repository uses Bun and `bun.lock`.

```sh
bun install
bun run dev
```

## Build and preview

```sh
bun run build
bun run preview --port 8787
```

The production build is a Cloudflare Worker generated by Nitro. The preview command serves that build with Wrangler.

## Supabase configuration

Configure these variables in the local environment and the production deployment:

- `VITE_SUPABASE_URL` and `VITE_SUPABASE_PUBLISHABLE_KEY` for browser requests.
- `SUPABASE_URL` and `SUPABASE_PUBLISHABLE_KEY` for server-side public requests.
- `SUPABASE_SERVICE_ROLE_KEY` for server-only administrative operations. Never expose this key to browser code.

Apply database migrations from `supabase/migrations/` through the project's Supabase deployment process.

## Routes

- `/` — public home page and published-property catalogue.
- `/properties/:id` — published property details.
- `/privacy`, `/cookies`, `/terms`, `/data-request` — legal and data-rights information.
- `/auth`, `/reset-password`, and `/admin/*` — authentication and staff tools; these are not public indexable pages.
- `/sitemap.xml` and `/robots.txt` — crawler discovery.

Property listings and site settings are loaded from Supabase. Keep public contact details and business claims in the site settings accurate, and review legal information with the responsible business owner before publication.
